# Banking Management System

## 📌 Overview
The **Banking Management System (BMS)** is a desktop-based application developed using **Visual Basic 6.0**.  
It is designed to manage basic banking operations such as customer accounts, transactions, and balance enquiries.

This project is intended for **academic and learning purposes**, demonstrating the use of VB6 forms, modules, and database connectivity.

---

## 🛠️ Technology Stack
- **Programming Language:** Visual Basic 6.0
- **Platform:** Windows
- **IDE:** Microsoft Visual Basic 6.0
- **Database:** MS Access (.mdb) *(if used)*

---

## 🚀 Features
- User Login & Authentication  
- Customer Account Management  
- Deposit & Withdrawal  
- Balance Enquiry  
- Transaction Records  
- Simple and user-friendly interface

## ⚙️ Installation & Setup

### 1️⃣ Prerequisites
- Windows OS
- Microsoft Visual Basic 6.0 installed

### 2️⃣ Steps to Run
1. Open **Visual Basic 6.0**
2. Click **File → Open Project**
3. Select the `.vbp` project file
4. Press **F5** or click **Run** to execute the application
